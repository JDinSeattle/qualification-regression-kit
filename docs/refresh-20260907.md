# Fail-closed qualification and process cleanup

Reviewed and implemented 2026-09-07.

The old output gate treated JSON true as integer protocol version 1. The new gate requires exact integer protocol and typed finite measurements. Each worker starts a new process session; a timeout kills its process group, reaps the direct child, and preserves partial stdout/stderr. A real child/grandchild regression checks that the descendant cannot write its delayed marker.

## Why this scope

Backend: bounded external work and diagnosable failure. ML infrastructure: compatibility gates, independent oracles and measured qualification. [Dated official hiring and release review](market-review-20260907.md). Other portfolio projects already cover distributed queues and cloud provisioning; this change addresses defects at this repository’s own boundary. No additional framework is required.

## Tradeoffs and limits

Process groups cover ordinary descendants, not processes deliberately escaping the session. This runner is not a security sandbox. The numerical defect remains a deliberately injected mutation.

These are local CPU/Linux experiments with test-owned faults. No production traffic, cloud deployment, GPU execution, user count or service-level availability is inferred. Timing campaigns retain environment, raw samples and their original comparison method; this maintenance does not claim a performance improvement.
